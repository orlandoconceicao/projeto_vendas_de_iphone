# Landing Page do iPhone 13 Pro

Interface de estudo inspirada na apresentação do iPhone 13 Pro, criada para praticar layout responsivo e interatividade com JavaScript.

## Funcionalidades

- apresentação visual do produto;
- seleção entre as cores disponíveis;
- troca dinâmica da imagem;
- destaque da opção selecionada;
- adaptação para diferentes tamanhos de tela.

O projeto é uma demonstração de interface e não implementa carrinho, pagamento ou integração com backend.

## Tecnologias

HTML5, CSS3, JavaScript, DOM, Flexbox e media queries.

## Execução

Abra o arquivo `index.html` no navegador.
